# 🚗 Vehicle Parking Management System

A web-based Vehicle Parking Management System designed to manage parking slots, track vehicle entry & exit time, maintain records, and generate parking information efficiently. The system helps replace manual registers and makes the process digital and faster.

---

## 📌 Features

- Vehicle entry registration
- Vehicle exit registration
- Parking slot availability
- Vehicle details list
- Search vehicles easily
- Track parking duration
- Basic reporting / logs
- Fully user-friendly design
- Responsive UI
